# It's A Cuppie project instructions

These rules extend `~/Projects/AGENTS.md` and apply to the itsacuppie.com
site. `README.md` owns setup, editing, images, hosting and DNS.

## Pushing is publishing

A push to `main` goes live on https://itsacuppie.com through GitHub Pages,
usually within a couple of minutes. There is no staging site.

- Before any push to `main`, preview the change locally (`README.md`, "Preview
  locally before pushing"), then tell the owner in a line or two what will
  change on the live site and ask whether to push. Push only after a yes.
- After a push, open the live page and confirm the change shows.
